# Imágenes de Bodegol

rutas, dimensiones, formato, peso máximo y orientación de cada imagen.

- fields/, food/, drinks/, events/, packages/ → 1200×900 (4:3)
- gallery/ → 1200×800 (3:2)
- promotions/ → 1080×1080 (1:1)
- logos/og-image.jpg → 1200×630
